# AutoAgenda Web Agent Guidelines

This project uses the local Karpathy-inspired coding guidelines in:

`skills/karpathy-guidelines/SKILL.md`

When editing this project:

- Think before coding and state assumptions when they matter.
- Prefer simple, direct fixes over broad rewrites.
- Make surgical changes tied to the requested issue.
- Define a clear verification step for each non-trivial change.
- Do not refactor unrelated code while fixing a bug.
